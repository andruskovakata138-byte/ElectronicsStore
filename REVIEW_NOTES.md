# Состояние комплекта

Разделы 1.1–1.4 сохранены без редактирования, включая исходные таблицы и рисунок. В них остаются исходное упоминание фотостудии в 1.4, неполная фиксация UI-технологии, а также разница между текстовым перечнем ролей и старой диаграммой. Это следствие прямого требования сохранить разделы. В 1.5 уточнены единые роли и новая модель.

Доступ ADO.NET сохранен по решению таблицы 3. Из порядка выполнения применены Avalonia, .NET 10, SQL Server, разделение модулей, транзакции, проверка прав, запуск и перенос. EF Core из учебного примера не добавлен поверх ADO.NET.

Пока не выполнены: сборка C#, запуск SQL на сервере, интеграционные и интерфейсные испытания, реальные снимки экранов, публикация в удаленный репозиторий. Нельзя утверждать, что все функции проверены и работают корректно. Макеты в записке не являются скриншотами.

На компьютер пользователя оставлены только настройки экземпляра SQL Server и выполнение команд из README. Автоматически установить Visual Studio или SQL Server на компьютер пользователя из этой среды невозможно.
