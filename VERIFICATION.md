# Проверка комплекта

Выполнено в среде подготовки:
- Проверка XML всех AXAML и CSPROJ.
- Подсчет CREATE TABLE и REFERENCES: 8 таблиц, 8 внешних ключей.
- Независимая проверка четырех PBKDF2-хэшей учебного пароля.
- Проверка пяти расчетных примеров средствами Decimal в Python.
- Точное сравнение XML разделов 1.1–1.4 исходной и дополненной записки: совпадают текст, форматирование, таблицы и рисунок.
- Отрисовка и визуальная проверка пояснительной записки: 25 страниц до приложений, 37 страниц всего.

Не выполнялось: dotnet build, исполнение тестового C# проекта, запуск SQL в SQL Server, испытания UI и конкурирующих продаж. В среде нет .NET SDK и SQL Server, загрузка SDK недоступна. Макеты не являются скриншотами.

Для выполнения этих проверок на Windows: README_RU.md, CHECK.cmd и docs/TEST_PLAN.md.
